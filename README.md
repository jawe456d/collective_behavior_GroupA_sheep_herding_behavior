# Collective Behavior
Repository for the tasks for the 2026/2027 Winter Semester in Collective Behavior 

The group's members are:
Daurian Garnier(Daurian-Garnier) and Kenny Weidemann(jawe456d)

Our plan is to model the behavior of a flock of sheep, especially in regard to their reaction to herding dogs and/or predators.
A jump off point is the paper "Collective responses of flocking sheep (Ovis aries) to a herding dog (border collie)" (https://www.nature.com/articles/s42003-024-07245-8) where the response of a flock of sheep to a border collie is both described and modeled. Further "Intermittent collective dynamics emerge from conflicting imperatives in sheep herds" (https://www.pnas.org/doi/10.1073/pnas.1503749112") describes observations regarding the behavior of sheep when undisturbed in comparison to the startle response displayed when a percieved threat approaches.

We aim to model these behaviors. Java code will be used.

Milestone 1:
Provide an overview of existing literature regarding the collective behaviors in sheep flocks

Milestone 2:
Model basic behavior (spreading out to graze when relaxed, basic startle response)

Milestone 3:
Model the more complex fleeing behaviors and the movement of the herding dog
